# Датасет 732 прогонов OPM Flow по Model_Z

Отклики симулятора для обучения суррогата (задача 34). Считались на сервере
`89.169.2.178` с 16 по 17 августа 2026 года, около 200 машино-часов OPM Flow
в контейнере `openporousmedia/opmreleases:latest`. Сервер погашен, поэтому
данные лежат здесь.

Основной репозиторий кода — [aios-hack/aios](https://github.com/aios-hack/aios),
там же правило, по которому `data/` не хранится в гите и адресуется хешами.
Этот репозиторий — сознательное исключение: пересчёт датасета стоит слишком
дорого, чтобы держать его в одном экземпляре на одном диске.

## Что внутри

| Каталог | Прогонов | Строк манифеста |
|---|---|---|
| `dataset-main/` | 200 | 1200 |
| `dataset-extra-500/` | 532 | 2232 |

Строк в манифесте больше, чем прогонов: попадания в кеш пишутся отдельными
записями, поэтому один и тот же `canonical_schedule_hash` встречается
несколько раз. Уникальных расписаний — 200 и 499 соответственно.

В каждом прогоне лежит пара, которую читает загрузчик отклика:

```
runs/<run_id>/output/MODEL_Z.SMSPEC
runs/<run_id>/output/MODEL_Z.UNSMRY
```

У 700 прогонов этим и ограничивается: `bridge/dataset.py` компактизирует
каталог после успешного разбора отклика. У 32 прогонов `dataset-extra-500`
компактизация не сработала, и там сохранились полные выходы Flow — INIT,
EGRID, DBG, PRT, UNRST, ESMRY. Они перенесены как есть, хотя
`bridge/response_loader.py` их не читает, а INIT и EGRID вообще одинаковы
у всех прогонов, потому что сетка одна.

Рядом лежит происхождение: `manifest.jsonl` со статусами и хешами,
`plan.json` со спецификациями сценариев, `decks/` с эмитированными деками,
`cache/` с ключами кеша, `cycle*.json` и `cycle-events.jsonl` с состоянием
цикла обучения, `model-task34-700/feature_context.json` с контекстом
фичеризации.

## Семейства сценариев

| Семейство | `dataset-main` | `dataset-extra-500` |
|---|---|---|
| LEVELS | 550 | 1055 |
| UNREACHABLE | 200 | 300 |
| SHUTDOWN | 175 | 261 |
| CONVERSION | 70 | 111 |
| BASELINE | 5 | 5 |

Числа по строкам манифеста. Семейство UNREACHABLE существует специально:
без сценариев, где скважина упирается в предел по забойному давлению
и не добирает заданный режим, суррогат выучит тождество «дебит равен уставке»
и обвалит давление в руках оптимизатора.

## Базовый прогон и снимок сервера

`base_run/` — базовый прогон с сервера целиком: эмитированный дек
(`deck/Model_Z*.inc`, 79 МБ, дублирует `docs/models/Model_Z`), полный набор
выходов Flow и лог запуска. Именно на его отклике обучена базовая линия CRM.

`server-snapshot/` — то, что осталось бы потерянным вместе с машиной:

| Файл | Что это |
|---|---|
| `environment.txt` | `pip freeze` venv, версия Python, digest образа OPM, процессор, память, версия ОС |
| `inventory.tsv` | полный список 30 074 файлов сервера с размерами |
| `bash_history.txt` | история команд root: чем запускалась генерация датасета и обучение |
| `bashrc.txt`, `zshrc.txt`, `profile.txt` | шелл-конфигурация |
| `impeccable/config.json` | конфигурация линтера рабочей копии |
| `out/` | `npv.json` и `wells_schedule.inc`, оставшиеся от прогонов CLI |

Пароль дашборда в истории команд заменён на заглушку.

С сервера сознательно не забрано: `~/.venv` (пересобирается из
`pyproject.toml`), `~/.cache` 1.1 ГБ (кеши pip и http), `~/.local` 166 МБ
(утилиты, поставленные через pip), образ `openporousmedia/opmreleases`
(качается из реестра по digest из `environment.txt`). Всё это видно
в `inventory.tsv`, если понадобится сверить.

Машина `msk-1-vm-5dzq`: Ubuntu 26.04, AMD EPYC-Rome 32 ядра, 62 ГБ памяти,
без GPU. Обучение шло на CPU, torch 2.13.0+cpu.

## Как использовать

Клонировать рядом с `aios` и указать на каталог датасета:

```bash
git clone https://github.com/aios-hack/dataset-700.git
```

Дальше либо скопировать нужный каталог в `aios/data/`, либо передать путь
напрямую в `surrogate.train --dataset-root`. Сиды планов: `20260816`
для `dataset-main`, `20260817` для `dataset-extra-500`.

Все 732 прогона завершились со статусом `OK`, ни одного отказа Flow.
Замер времени одного прогона на свободной машине — 513 с, при конкуренции
за ядра — 1749–1857 с.
